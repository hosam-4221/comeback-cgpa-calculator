CGPA Buddy — GPA & Retake Planner

How to use:
1. Extract this folder from the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. The page starts empty. Click + Add course, enter the course name, choose credits, then choose current and target grades.
4. Use Export CSV to save a spreadsheet-friendly list.

Works offline. Your entries save automatically in this browser. Use Clear all to remove all courses and CGPA inputs.
